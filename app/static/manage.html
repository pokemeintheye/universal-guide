Guide lineup

Arrange channels from every provider, including virtual channels. Drag a row, enter a position, or use the arrows. Uncheck Enabled to hide that channel from the Apple TV guide; its playback source settings stay unchanged. Save changes, then refresh the Apple TV guide.

Channels DVR sources

Stations discovered in Channels DVR appear below. Add any discovered station, choose Channels DVR or Philo as the primary live source, and save. Changes apply at the next guide refresh without Docker or TestFlight rebuilds. Philo must already have a matching channel link for Philo playback.

Plex virtual channels

Create a repeating 24/7 schedule from movies or episodes already indexed in Plex. Each program opens through the existing Plex player; true automatic continuous playout between programs is not included yet. Choose approximate runtime per item (minutes).

New virtual channel

Build a channel automatically from matching Plex content. Within a filter category, selections match any; across metadata categories (genres, labels and tags), filters must all match. For Movies + TV, choosing TV shows includes those episodes separately from movies matching the selected metadata filters. Select a genre, label or tag to include movies alongside selected shows; a TV-show-only selection does not add every movie. The schedule remains consistent across guide refreshes and updates after a Plex library sync. Hold Ctrl/Command to select multiple genres or TV shows; leave blank for all.

These new ordering choices override the existing Order setting separately for TV and movies. For a mixed channel, TV episodes retain their selected order while movies are inserted between episodes. Each Plex Collection plays as one uninterrupted block, in release-date order (year fallback). Movies in more than one collection are assigned to one collection to avoid duplicate plays. Run a Plex library sync after updating Docker to load Collection metadata.

Combine conditions with AND, OR, and NOT groups. IS ONLY selects one exact genre. To require ONLY Comedy and Drama together (and no other genres), put Genre → Is only → Comedy and Genre → Is only → Drama in the same ALL (AND) group. A single IS ONLY Comedy matches Comedy-only titles. IS ONLY NOT excludes that exact genre-only match. Missing genre metadata matches neither exclusive operator. Nest OR/NOT groups for other combinations and exceptions.

Actual Plex runtime is used when available; defaults only apply to older items missing runtime metadata.

Exclude removes the title from this channel even when the rules match. Restore adds it back. Changes are saved when you save the virtual channel. Use the pages or title search to review every match.

Manual additions and exclusions

Search for any Plex movie or episode. Add forces it into the channel even if no rules match; Exclude removes it even if rules match. Additions are played after the rule-generated items. Exclusions remain in effect after syncing Plex.
