# Approved Universal Guide tvOS branding

The finalized Universal Guide artwork is the purple **UG / Universal Guide** design selected for the Apple TV icon. Do not alter the logo, text, or colors.

Upload the prepared landscape PNG to this folder and name it exactly:

`UniversalGuideIcon.png`

The file should be **1280 × 768 pixels**, and the GitHub Actions workflows will generate the layered Apple TV home-screen and App Store icons plus Top Shelf imagery from it.

Source is intentionally not committed as a text placeholder. Download the approved PNG from the ChatGPT conversation, and upload it to this folder with GitHub **Add file → Upload files**. The unsigned simulator build can run without the source image, but the TestFlight workflow requires it.
